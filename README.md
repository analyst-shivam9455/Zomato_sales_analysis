# Zomato Sales Analysis

##### Overview :This project provides an in-depth analysis of Zomato's restaurant data using Power BI. It covers various aspects such as restaurant distribution, ratings, cuisine popularity, online order trends, and more.

## Key Insights
- #### Total Hotels:- 8743
- #### Total Votes:- 15M
- #### Average Rating :- 3.7
- #### Average cost(for two people) :- 416.63
- #### % of resturant offers online order :- 58.87
- #### % of restaurant offers table booked :- 12.47

### Restaurant Distribution by City
- Top areas: BTM, Koramangala (4th–7th Block), Jayanagar, JP Nagar, HSR Layout
- BTM has the highest number of restaurants (2.03K+)

### Restaurant Type Split
- Delivery: 42.6%  
- Dine-out: 41.02%  
- Desserts, Cafes, Buffets, Pubs make up the rest

### Online Order Analysis
- 54.02% of restaurants offer online orders
- 45.9% do not offer online orders

### Popular Cuisines
- Most offered: North Indian, South Indian, Chinese, Biryani, Desserts, Fast Food

### Top Restaurants by Number of Votes
- Onesta (348K votes)
- Truffles (301K votes)
- Empire Restaurant, Hammered, The Black Pearl, and more
